# 🔍 Campus Lost & Found System
💡 Project Idea
A smart web-based platform that helps students find their lost belongings and return found items to their rightful owners.
📝 Problem Statement
Students often lose important belongings such as:
College ID cards
Books and notebooks
Calculators
Earphones
Water bottles
Finding these items on a college campus can be difficult.
🚀 Proposed Solution
A website where students can report lost and found items.
⚙️ Key Features
Report Lost Item: Upload an image and provide item details.
Report Found Item: Students can post details about items they find.
Location Details: Mention where the item was lost or found.
Item Matching: Help connect lost-item reports with found-item reports.
Ownership Verification: Verify the owner's claim before handing over an item.
🎯 Objective
To make college campuses safer and more organised by helping students recover their lost belongings.
